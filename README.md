# EduChat

EduChat is a **full-stack real-time chat application** built for classrooms and study groups.  
It allows students and teachers to **log in securely, join class-specific chat rooms, and exchange messages and images instantly**.  
The goal is to provide a lightweight, distraction-free alternative to mainstream messaging apps — perfect for quick collaboration in an educational setting.

## ✨ Features
- 🔐 **Authentication** – Login and registration system for secure access  
- 💬 **Real-time messaging** – Instant text chat with classmates  
- 🖼️ **Image sharing** – Share pictures, diagrams, and notes easily  
- 🎯 **Class-focused** – Each chat is designed for specific groups or sessions  
- ⚡ **Lightweight design** – Quick and easy to use in a classroom environment  

## 🚀 Tech Stack
- **Frontend:** React (with hooks and components)  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose ODM)  
- **Real-time Communication:** Socket.IO  
- **Authentication:** JWT + bcrypt  

## 📌 Future Improvements
- ✅ Temporary room codes for instant session-based chats  
- ✅ Message reactions and pinned messages  
- ✅ Anonymous Q&A mode for shy students  
- ✅ Optional chat expiration after sessions  

## 🎓 Use Case
EduChat is designed primarily for **teachers and students** who need a fast, secure, and focused platform to collaborate during lectures, workshops, or group studies.
